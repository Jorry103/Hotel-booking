# 🏨 Hotel Booking System

A *Java desktop application* with a modern graphical interface (GUI) using *Swing*, designed to manage hotel room bookings easily and efficiently.

---

## 📌 Features
- 📝 Book a room by entering customer details
- 🛏 Choose room types: Single, Double, Suite
- 🔄 Auto-generate room numbers based on availability
- 📋 View all current bookings
- 📁 Data stored in-memory (future upgrade: file/database)

---

## 🧪 Technologies Used
- ☕ Java  
- 🎨 Swing (GUI)  
- 🧠 Developed with Eclipse IDE

---

## 🚀 How to Run
1. Clone or download the project.
2. Open it using *Eclipse*.
3. Run the HotelMainWindow.java file.
4. Click *"Book Now"* to start booking or *"View Bookings"* to see existing ones.
